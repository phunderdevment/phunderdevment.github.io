Home Assistant — private Smarthome-Instanz

Persönliche Installation zur Steuerung der eigenen Geräte im eigenen Haushalt.

Worum es geht

Diese Seite gehört zu einer privaten Installation der Open-Source-Software Home Assistant, die im eigenen Haushalt auf eigener Hardware betrieben wird. Sie ist kein öffentliches Angebot, hat keine Nutzerkonten und steht niemandem ausser dem Betreiber zur Verfügung.

Funktionsumfang

Home Assistant führt die Geräte des Haushalts an einer Stelle zusammen und stellt sie auf selbst gestalteten Übersichtsseiten dar. Konkret werden damit

  • Kameras und die Türklingel angezeigt sowie deren Bewegungs- und Klingelereignisse empfangen,
  • Heizung, Licht und Storen gesteuert,
  • Sensorwerte wie Temperatur oder Luftfeuchtigkeit aufgezeichnet,
  • Abläufe automatisiert, etwa eine Benachrichtigung beim Klingeln an der Haustür.

Zugriff auf Google-Geräte

Für die Einbindung der eigenen Google-Nest-Geräte nutzt diese Installation die Smart Device Management API von Google. Der dafür eingerichtete OAuth-Client dient ausschliesslich dazu, dass sich der Betreiber mit seinem eigenen Google-Konto bei seiner eigenen Home-Assistant-Instanz anmeldet und diese auf seine eigenen Geräte zugreifen darf. Welche Daten dabei verarbeitet werden, steht in der Datenschutzerklärung.
